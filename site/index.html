gmail-tui

A Gmail client for your terminal — built with Charm.

Inbox, threads, search, compose/reply/forward with attachments, labels, themes and IMAP IDLE push — no Google Cloud project, no OAuth: just an App Password.

Get started GitHub

Features

Inbox & threads

Threaded inbox with IMAP IDLE push — new mail appears without polling. Open a thread and read message by message.

Compose, reply, forward

Markdown composer with Tab field navigation and a send confirmation, adapted from charmbracelet/pop.

Search

Gmail-style search: from:x is:unread label:Work has:attachment — plain words match text.

Labels, archive & stars

Apply or remove labels, archive, star and mark read/unread without leaving the keyboard.

Attachments

Attach files when composing, open HTML bodies in the browser, and save parts with :save <n> [path].

12 themes

Embedded themes switchable at runtime with :theme <name> — instant preview, persisted to config.

Quickstart

$brew install andsigno82/gmail-tui/gmail-tui # or: go install github.com/andsigno82/gmail-tui/cmd/gmail-tui@latest
$gmail-tui login # first-run wizard — App Password stored in the system keychain
$gmail-tui # or: export GMAIL_APP_PASSWORD=xxxx first

Requires a Gmail account with 2-Step Verification and an App Password — regular passwords do not work with IMAP/SMTP. See the full README.

Keymap

KeyAction
j / k, ↑ / ↓move cursor (list) / scroll (thread)
Enteropen selected message
Esc / q, Ctrl+Cback / quit (Ctrl+C quits from anywhere)
/search — from:x is:unread label:Work has:attachment
r / f / creply / forward / compose new
a / sarchive / star on-off
l / vapply-remove label / mark read-unread
?full help overlay

Mouse works too: wheel scrolls, click selects, double-click opens. Full keymap in the README.
